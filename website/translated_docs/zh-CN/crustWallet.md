## Crust钱包安装指南 
波卡生态系统现已支持多个钱包与Crust主网（Mainnet）及平行链（Parachain）的兼容，这些钱包经过上万名社区用户的实际测试，确保了其高稳定性和可靠性。此外，这些钱包还支持波卡（Polkadot）和以太坊（Ethereum）生态，能够为用户提供更好的资产管理与交互体验。

为了进一步提升用户体验，Crust将继续支持更多波卡生态钱包，以推动生态的建设与发展。目前，我们优先推荐以下三款钱包供用户使用：

### 1）Subwallet
Subwallet 是一款非托管的波卡和以太坊钱包，提供浏览器插件、移动应用以及Web dashboard 多种形式，方便用户随时随地进行资产管理。它支持波卡主网及平行链，并且能够跨链操作，适合多元化的数字资产管理需求。

下载链接：点击此处下载[Subwallet](https://www.subwallet.app/download.html)

### 2）Talisman
Talisman 是一款创新的波卡生态钱包，提供简洁且高效的用户界面，并具备强大的跨链功能，能够提升用户的资产管理和链间交互体验。它的设计目标是为波卡用户提供更加流畅、安全的操作环境，特别适合波卡生态中的各种DApp交互。

下载链接：点击此处下载[Talisman](https://talisman.xyz/download)

### 3）Crust Wallet
Crust Wallet 是一款基于 Google Chrome 浏览器的插件钱包，专为Crust Mainnet主网设计。用户可以通过Crust Wallet管理自己的CRU资产，并与Crust网络上的DApp（如Crust Apps）进行交互。

需要注意的是，Crust Wallet 仅支持与Crust Mainnet网络进行交互，**不支持Crust平行链和ERC20上的CRU代币**。

下载链接：点击此处下载[Crust Wallet](https://chromewebstore.google.com/detail/crust-wallet-v3/bhnjponmcdginfhpmfnplhoajoolcfhh)

**特别说明：**

Crust Wallet插件钱包最新版本为'Crust Wallet V3', Chrome web store中的旧版本'Crust Wallet'插件已经失效，已经安装旧版本Crust Wallet的用户请按以下流程进行迁移：

  1. 从旧版Crust Wallet中导出助记词，并确保做好安全备份;
  2. 将旧版Crust Wallet插件从Chrome浏览器中删除;
  3. 从Chrome web store中安装最新版本的[Crust Wallet V3](https://chromewebstore.google.com/detail/crust-wallet-v3/bhnjponmcdginfhpmfnplhoajoolcfhh)插件;
  4. 导入从第一步导出的助记词;
  5. 迁移结束;

**账户安全提示：**

***在Crust Wallet中创建新账户时，请务必妥善保管账户的助记词和备份文件。由于钱包是非托管的，一旦丢失助记词或备份文件，您将无法恢复账户或找回账户中的资产，因此务必确保备份安全。***
